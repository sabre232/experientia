Code-Stil:
- Dem bestehenden Repo-Stil folgen (Einzug, Benennung, Import-Reihenfolge); neuer Code bleibt mit dem benachbarten Code konsistent; NIEMALS dabei unzusammenhängende Dateien neu formatieren.
- Kommentare nennen nur Beschränkungen, die der Code selbst nicht ausdrücken kann; kein Fülltext wie „hier wird X aufgerufen“.

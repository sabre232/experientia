Bei einer Datenvisualisierung einhalten:

Diagrammtyp passend zum Inhalt:
- Trend → Linie; Vergleich → Balken; Zusammensetzung → gestapelt/Kuchen (≤ 5 Kategorien); Verteilung → Histogramm/Boxplot; Zusammenhang → Streudiagramm.
- Bevor der Typ gewählt wird, fragen „was soll der Leser sehen“; nie 3D/Kuchen um der Optik willen.

Achsen und Ehrlichkeit:
- Balkendiagramm: Y-Achse startet bei 0 (Abbruch überzeichnet die Differenz); eine abgebrochene Linie muss gekennzeichnet sein.
- Doppelte Achse sparsam; wenn unvermeidbar, Ausrichtung von Einheiten und Nullpunkten klar erklären.
- Nie irreführende Diagramme (Abbruch, nichtlineare Achse, irreführende Farben).

Weniger ist Mehr:
- Ein Diagramm = eine Information; Gitterlinien, Ränder, Legenden ohne Information löschen.
- Farbe hat Bedeutung (Unterscheidung/Hervorhebung); nie Regenbogenfarben ohne Unterscheidung; an Farbschwäche denken.

Beschriftung:
- Der Titel sagt die Schlussfolgerung; zentrale Punkte direkt im Diagramm beschriften (Pfeil/Text); nie nur Achsen ohne Beschriftung.
- Das Trio Einheit / Zeitraum / Datenquelle ist komplett.

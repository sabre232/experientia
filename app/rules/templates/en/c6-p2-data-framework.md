Doing data analysis, use the three-part form:

1. Trend (what happened):
- Overall trajectory + key inflection points; speak in data (values + time window + YoY/MoM convention).
- Distinguish "statistical noise" from "real change"; don't conclude on small samples.

2. Attribution (why):
- Decompose by dimension to find contributors (channel/region/cohort); mark the main contributors.
- Distinguish correlation from causation; with only correlational evidence, write "correlated, not causal".
- List hypotheses to verify — NEVER present guesses as conclusions.

3. Recommendation (what to do):
- Each recommendation maps to a finding; actionable, with owner and deadline.
- Note expected impact and risk; "keep watching" is a valid recommendation.

Discipline: state conventions (time window/dedup/unit) up front; every conclusion traceable to data.

En concevant une grille d'évaluation (rubric), respecter :

Structure :
- Lignes = dimensions d'évaluation (3-5, centrées sur les compétences clés), colonnes = niveaux (ex. 4=excellent / 3=acquis / 2=à améliorer / 1=non acquis).
- Chaque cellule porte une « description comportementale » — à ce niveau, à quoi ressemble le travail/la performance, avec des termes observables ; jamais de mot flou comme « correct / moyen ».

Discipline :
- Les dimensions ne se chevauchent pas (contenu, structure, langue, application, chacune sa part).
- Les descriptions de niveau se distinguent du bas vers le haut ; la différence entre deux niveaux voisins doit se formuler.
- Donner 1-2 exemples (bon/mauvais en contraste) pour aider l'utilisateur à caler le standard.

Usage :
- Noter dimension par dimension en se référant aux descriptions ; jamais de note globale à l'impression.
- La grille est montrée aux apprenants d'abord (standard transparent), puis utilisée pour évaluer.

Sortie : tableau de la grille + note d'usage + exemples en contraste.

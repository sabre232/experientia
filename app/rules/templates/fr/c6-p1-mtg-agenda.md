En rédigeant un ordre du jour de réunion, respecter :

Structure (chaque point avec timebox) :
- Sujet + durée + responsable + objectif (quel livrable : décision / synchronisation / brainstorming).
- Marquer les points « décision » — ils doivent porter une question précise à trancher.
- Durée totale ≤ durée de la réunion - 10 min de tampon ; les points à risque de dépassement en rouge.

Discipline :
- D'abord se demander « cette réunion peut-elle se résoudre par e-mail/doc » ; si oui, ne pas la convoyer.
- Les points « décision » exigent l'envoi des supports avant la réunion (sinon lecture à la volée, perte de temps).
- Chaque point porte les « entrées nécessaires », pour que les participants viennent avec des réponses.

Sortie :
- Ordre du jour + participants (qui est indispensable, qui est optionnel) + liste des supports avant réunion.
- Prévoir un bloc « divers / parking », les sujets hors sujet sont notés pour être traités après.

NEVER : NEVER convoquer sans ordre du jour ; NEVER mettre « on en discute » comme point d'ordre du jour (il faut une question précise).

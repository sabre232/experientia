Al hacer un SWOT, respetar:

Cuatro cuadrantes (cada punto con un argumento, no discurso vacío):
- Strengths / Weaknesses (fortalezas / debilidades): interno, verificable (datos, recursos, capacidades).
- Opportunities / Threats (oportunidades / amenazas): externo, con fuente (mercado, política, movimiento competidor + fecha).

Disciplina:
- Cada punto se marca « hecho » o « juicio »; un juicio debe poder dar su argumento.
- Las debilidades/amenazas no se esquivan; un SWOT que solo escribía fortalezas no tiene valor.

Estrategias cruzadas (entregable clave):
- SO (usar las fortalezas para captar las oportunidades), WO (completar las debilidades para captar las oportunidades), ST (usar las fortalezas para frenar las amenazas), WT (defensa).
- 1-2 estrategias accionables por cuadrante, con prioridad marcada.

Salida: tabla SWOT + lista de estrategias cruzadas + « las 3 acciones más críticas ».

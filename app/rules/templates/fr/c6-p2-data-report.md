En écrivant un rapport de données, respecter :

Résumé d'abord :
- 3-5 phrases en tête pour la conclusion (ce qui s'est passé, pourquoi, que recommander) ; le lecteur qui ne lit que le résumé peut déjà décider.
- Chaque chiffre du résumé doit être retrouvé dans le corps.

Corps :
- Organiser en « contexte → méthode/périmètre → constats → recommandations » ; chaque constat est accompagné d'un graphique ou d'un tableau.
- Normes de graphiques : titre (qui dit la conclusion, pas le sujet), unité, période, source de données.
- Les chiffres clés en gras ou colorés ; jamais de laisser le lecteur les chercher.

Annexe :
- Explication des périmètres, données détaillées, détails de méthode dans l'annexe ; le corps ne garde que l'essentiel.

Discipline :
- Les données sensibles/identifiables sont anonymisées ; jamais de détails bruts dans un rapport externe.
- Si la conclusion contredit les données, les données font foi ; corriger la conclusion, pas les données.

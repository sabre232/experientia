En traitant un texte immobilier/location, respecter les lignes rouges anti-discrimination (réf. le droit français de la non-discrimination, art. 225-1 du Code pénal et L.571-1 du Code de la construction et de l'habitation ; autres juridictions selon leur droit local) :

NEVER dans le texte :
- Décrire le « locataire/acquéreur idéal » selon la race, l'origine, le sexe, la grossesse, la situation familiale, l'apparence, le nom, l'état de santé, le handicap, l'âge, les opinions, l'orientation sexuelle, la religion, etc.
- Utiliser une formulation suggestive pour filtrer une population (« idéal pour jeunes actifs », « calme, parfait pour seniors » et autres expressions orientées vers une caractéristique protégée).
- Suggérer des conditions/prix différents selon la population.

Pratique conforme :
- La description du bien se concentre sur le bien lui-même (agencement, surface, luminosité, équipements, localisation), sans décrire « pour qui c'est ».
- Standard unique : tous les candidats passent par le même filtre (solvabilité / revenus / dossier) et le standard est documenté.
- L'adaptation raisonnable (par ex. aménagement pour handicap) doit pouvoir être traitée ; jamais de refus direct.

Discipline :
- Si l'on hésite sur la conformité d'une phrase, marquer « à revoir conformité » ; jamais de laisser passer par défaut.
- Ce modèle ne constitue pas un avis juridique ; pour une opération précise, consulter un avocat spécialisé en conformité immobilière.

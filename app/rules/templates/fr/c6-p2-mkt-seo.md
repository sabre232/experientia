En écrivant du contenu SEO, respecter :

Mots-clés :
- D'abord confirmer le mot-clé principal et 2-3 mots-clés longue traîne ; le mot principal entre dans le titre, le premier paragraphe, un sous-titre ; jamais de bourrage (une densité trop forte pénalise).
- Les mots-clés longue traîne sont répartis naturellement dans le corps et les sous-titres.

Métadonnées :
- Le titre (title) contient le mot principal + le bénéfice, ≤ 30 caractères.
- La description (description) contient le mot principal + une accroche d'action, ≤ 80 caractères, et tient seule comme résumé.

Structure et lisibilité :
- H1 unique, H2/H3 hiérarchisés ; paragraphes courts (≤ 4 lignes), beaucoup de listes.
- Les images ont un texte alt ; les liens internes pointent vers des articles anciens liés.

Discipline :
- Le contenu sert d'abord le lecteur, ensuite la recherche ; jamais de sacrifier la lisibilité pour placer des mots.
- Les données/cas sont réels ; jamais de formule fausse de type « le plus récent / autorité ».

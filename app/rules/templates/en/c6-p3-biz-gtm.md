Doing GTM, use this structure:

1. Target segment & positioning:
- Who to attack first (ICP, ideal customer profile) + one-line positioning (for whom, solves what, by what right).
- Explicit "who we won't target first", to focus resources.

2. Channels:
- Primary + secondary channels; each with "why + expected cost + expected conversion".
- Channels match the segment (B2B doesn't ride short video, and vice versa).

3. Cadence:
- Phased (warm-up / launch / scale / sustain); each phase has milestones and entry conditions for the next.
- Key dates (launch day, promo windows, dependency releases) made explicit.

4. Metrics & feedback:
- North star + 2-3 supporting metrics; each phase sets "hit/adjust/stop" lines.
- Data feedback loop: which channel works, which to cut.

NEVER: NEVER launch all channels at once (resource dilution); NEVER scale without a stop-loss line.

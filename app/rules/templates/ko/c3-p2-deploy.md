배포/운영 시 준수:

배포 전 반드시 확인 포인트를 출력하고 확인을 기다린다(경직성 제약):
- 나열: 영향 범위(어떤 서비스/환경), 데이터 마이그레이션(있으면 단계 나열), 예상 정지 시간, 롤백 방안.
- 프로덕션/돌이킬 수 없는 작업에 관여하면 명확한 확인을 받을 때까지 멈추고, 자동 실행하는 것은 NEVER.

롤백 계획:
- 각 변경마다 '어떻게 롤백할지'를 먼저 생각한다. 안전한 롤백 경로가 없으면 먼저 백업/스냅샷을 한다.
- 데이터 마이그레이션은 재진입 가능 스크립트로 쓴다(재실행해도 중복 적용되지 않음).

변경 기록:
- 변경 내용, 실행자, 시간을 기록한다. 프로덕션 설정을 흔적 없이 고치는 것은 NEVER.
- 시크릿/인증서는 코드 저장소에 넣지 않고, 키 관리 경로를 쓴다. 로그/스크린샷에 노출하는 것은 NEVER.

NEVER: 프로덕션 DB에 미연습 SQL을 직접 실행하는 것은 NEVER. 상호 의존하는 여러 서비스를 동시에 고치는 것은 NEVER.

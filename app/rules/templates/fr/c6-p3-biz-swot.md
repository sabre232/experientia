En faisant un SWOT, respecter :

Quatre quadrants (chaque point avec un argument, pas de discours vide) :
- Strengths / Weaknesses (forces / faiblesses) : interne, vérifiable (données, ressources, capacités).
- Opportunities / Threats (opportunités / menaces) : externe, avec source (marché, politique, mouvement concurrent + date).

Discipline :
- Chaque point est marqué « fait » ou « jugement » ; un jugement doit pouvoir donner son argument.
- Les faiblesses/menaces ne sont pas esquivées ; un SWOT qui n'écrivait que les forces n'a pas de valeur.

Stratégies croisées (livrable clé) :
- SO (utiliser les forces pour saisir les opportunités), WO (combler les faiblesses pour saisir les opportunités), ST (utiliser les forces pour bloquer les menaces), WT (défense).
- 1-2 stratégies actionnables par quadrant, avec priorité marquée.

Sortie : tableau SWOT + liste des stratégies croisées + « les 3 actions les plus critiques ».

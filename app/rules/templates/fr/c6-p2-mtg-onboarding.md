En concevant l'onboarding d'un nouvel arrivant, respecter :

Par étapes (typiquement 30/60/90) :
- Semaine 1 : environnement/accès/outils + découverte de l'équipe + lecture des docs clés + première petite tâche.
- Semaines 2-4 : suivre les flux existants + mentorat (buddy) + terminer seul 1-2 tâches à faible risque.
- Jours 30/60/90 : un jalon vérifiable par étape (ex. livrer un module seul).

Structure (chaque étape donne) :
- Objectif (ce que le nouvel arrivant doit savoir faire à la fin de l'étape).
- Liste (actions concrètes + responsable + signe de fin).
- Point de contrôle (qui fait un feedback 1:1 quand le jalon est atteint).

Discipline :
- Désigner un buddy (un pair hors hiérarchie) + un rythme de feedback clair (1:1 hebdo).
- Doc d'abord : tout ce que « seul quelqu'un connaît de vive voix » devient une doc ; NEVER laisser le nouvel arrivant deviner.
- Progression de difficulté : petit d'abord puis grand, avec une marge d'essai sécurisée.

Sortie : liste par étapes + tableau des jalons + tableau du rythme de feedback + liste des docs/liens clés.

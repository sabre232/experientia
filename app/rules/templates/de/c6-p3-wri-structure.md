Bei der Organisation der Textstruktur einhalten:

Pyramidenprinzip:
- Schlussfolgerung zuerst: den Hauptgedanken/die Antwort oben geben, dann die Stützen aufbauen.
- Jedes Level beantwortet nur die Frage des Levels darüber; der erste Satz des Absatzes ist seine These.

Ein Absatz, eine Idee:
- Ein Absatz = eine Sache; über 5 Zeilen, an Aufteilen oder eine Zwischenüberschrift denken.
- Parallelen Inhalt als Liste; nie eine lange Kette „und auch / außerdem“.

Logische Verknüpfung:
- Übergänge zwischen Absätzen (Kausalität, Gegenüberstellung, Progression); nie eine flache Aufzählung.
- Jedes Argument hat mindestens eine Stütze (Beispiel / Daten / Zitat); eine bloße Behauptung wird als „Beleg ausstehend“ markiert.

Prüfung vor der Abgabe:
- Abseitige Absätze löschen; die Konnektoren „zuerst / dann / zuletzt“ durch genauere logische Wörter ersetzen.

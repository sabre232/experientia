Writing ad/campaign copy, pick a framework by goal, one version each:

- PAS (Problem-Agitate-Solve): single-point pain conversion. State the problem -> amplify the cost -> solution + call to action.
- AIDA (Attention-Interest-Desire-Action): brand/long copy. Grab attention -> build interest -> create desire -> drive action.
- BAB (Before-After-Bridge): before/after contrast. Current state -> ideal state -> the product is the bridge.
- 4Ps (Picture-Promise-Proof-Push): high-ticket / trust needed. Paint the vision -> make the promise -> show evidence -> push to action.

General discipline:
- Every version ends with a clear CTA (one specific action command).
- Evidence (data/case/credentials) must be real and verifiable — NEVER fabricate.
- One selling point per message; NEVER cram five into one.

Repurposing one long piece across platforms, follow:

First extract the skeleton: core argument, key data, quotable lines, cases. All platform versions share the same factual source — NEVER let versions contradict each other.

Rewrite per platform (not just trimming):
- Blog/newsletter: full argument + section headings.
- Short post: single point + hook opener + hashtags.
- Video script: spoken short sentences + visual cues + pacing beats.
- Poster/infographic: 3-5 points + one main headline.

Discipline:
- The first 3 seconds decide stay-or-leave; put the hook first.
- Data/citations consistent across platforms; if a platform's length limit bites, cut examples not arguments.
- Label each version's platform and character count for direct paste.

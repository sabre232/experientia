You are working on a formal or official document (memorandum, official letter, circular). Follow the issuing organization's own document conventions — there is no single universal numbered standard, so when in doubt, ask rather than guess:

Required elements (missing any one = reject): sender (organization / department), reference number, recipient, date, subject line, body, closing, signature (name + title), attachments (if any), distribution / CC list.

Format rules (NEVER violate):
- The sender states the organization and department; the reference number is present and follows the organization's internal numbering rule.
- The date is in one consistent format throughout; the subject line is a precise noun phrase.
- The primary recipient (must act or respond) is kept separate from the CC / distribution list (informed only); never mix them.
- The signature carries name and title; every attachment is listed and actually attached.
- A classification or handling note (e.g. "confidential") sits at the top and is consistent with the distribution.

Self-check before delivery: sender present + reference number present + date consistent and matching the body + precise subject line + recipient/CC separated + complete signature + attachments listed and attached + handling note consistent.

Check the list point by point before delivering; when unsure of a convention (the organization's numbering, document type, handling notes), list the question and ask — NEVER guess the format.

Bei der Abwägung/Auswahl von Optionen einhalten:

Struktur:
- 2-4 Kandidaten-Optionen auflisten (inkl. „nichts tun“ als Baseline).
- 3-6 Bewertungsdimensionen (z. B. Kosten, Risiko, Tempo, Wartbarkeit), jede Dimension mit einem Gewicht (Summe = 100).
- Matrix-Bewertung (1-5), gewichtete Summe, die empfohlene Option ist markiert.

Disziplin:
- Jede Bewertung hat einen Satz Begründung; „Bauch-“-Dimensionen werden explizit als subjektiv markiert.
- Die Gewichte werden begründet (warum wiegt diese Dimension mehr); NIEMALS von einer gleichmäßigen Verteilung ausgehen.
- Die zentralen Annahmen auflisten (welche Bewertungen hängen an einer unüberprüften Prämisse); wenn sich eine Annahme ändert, wird die Schlussfolgerung neu berechnet.

Output:
- Empfohlene Option + ein Satz Begründung + Hauptrisiko + Auslösebedingung „wann wird die Option geändert“.
- NIEMALS nur Scores ohne Begründung geben.

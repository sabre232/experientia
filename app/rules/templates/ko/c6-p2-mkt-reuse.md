긴 글 한 편을 멀티 플랫폼 버전으로 재작성할 때 준수:

먼저 내용 골격 추출: 핵심 논지, 핵심 데이터, 명언, 사례. 모든 플랫폼 버전은 동일한 사실 출처를 공유하고, 각 플랫폼 버전의 사실이 상호 모순되는 것은 NEVER.

플랫폼별 재작성(단순 삭감이 아님):
- 공식 블로그/블로그: 완전한 논증 + 소제목 분단.
- 짧은 게시물: 단일 포인트 + 후킹 오프닝 + 주제 태그.
- 비디오 대본: 구어 짧은 문장 + 화면 지시 + 리듬 포인트.
- 포스터/인포그래픽: 3-5개 포인트 + 메인 타이틀 한 문장.

규율:
- 각 버전의 오프닝 3초에서 이탈 여부가 결정되므로 후킹을 맨 앞에.
- 데이터/인용은 플랫폼 간 일치; 특정 플랫폼 글자 수 초과 시 먼저 사례를 줄이고 논지를 줄이지 않는다.
- 출력 시 각 버전의 플랫폼과 글자 수를 표시해 바로 붙여넣을 수 있게.

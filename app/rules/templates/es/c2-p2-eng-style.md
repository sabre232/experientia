Estilo de código:
- Seguir el estilo existente del repo (sangrado, nomenclatura, orden de imports); el código nuevo se mantiene coherente con el código vecino; NUNCA reformatear de paso archivos sin relación.
- Los comentarios solo notan las restricciones que el código mismo no puede expresar; no rellenar con « aquí se llama X ».

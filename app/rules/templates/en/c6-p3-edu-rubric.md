Designing a scoring rubric, follow:

Structure:
- Rows = dimensions (3-5, focused on key abilities); columns = levels (e.g. 4=excellent / 3=meets / 2=developing / 1=below).
- Each cell a "behavior-based descriptor" — what work/performance "looks like" at that level, observable wording — NEVER vague "good/average".

Discipline:
- Dimensions don't overlap (content, structure, language, application each own their lane).
- Level descriptors distinguishable low-to-high; the difference between adjacent levels must be stateable.
- Provide 1-2 examples (good/bad contrast) to align raters.

Use:
- Score by checking each dimension against the descriptor — NEVER a holistic gut overall score.
- Show the rubric to students first (transparent criteria), then use it for assessment.

Output: rubric table + usage notes + example contrast.

En rédigeant un contenu pédagogique/scientifique, graduer les faits :

Gradation des faits :
- Certain (source autoritaire, vérifiable) : l'écrire, indiquer la source.
- À vérifier (en mémoire mais incertain / source douteuse) : marquer « [à vérifier] », jamais présenté comme un fait certain.
- Discutable/contesté (désaccord dans la communauté) : écrire « il existe des versions différentes », lister les principaux avis.

Discipline :
- Chiffrer, dater, nommer, citer un par un ; ce qui ne se vérifie pas est marqué « [à vérifier] » et listé en fin de texte.
- Pour le contenu manuel/examen, le périmètre suit la version imposée ; une version non conforme est signalée.
- « En général », « on dit que » ne servent pas de source.

Sortie :
- Corps (avec marquage [à vérifier] en ligne) + « liste des points à vérifier » en fin de texte (point par point : contenu + pourquoi c'est douteux + source de vérification conseillée).
- Rappeler à l'utilisateur : les points [à vérifier] doivent être vérifiés à la main avant usage officiel.

NEVER : NEVER inventer une source/page pseudo-autoritaire pour faire complet.

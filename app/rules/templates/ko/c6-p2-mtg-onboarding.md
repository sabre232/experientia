신입 온보딩을 설계할 때 준수:

단계 구분(전형 30/60/90):
- 1주차: 환경/권한/도구 + 팀 소개 + 핵심 문서 읽기 + 첫 작은 태스크.
- 2-4주차: 기존 프로세스 동석 학습 + 버디제 + 저위험 태스크 1-2건 독립 완료.
- 30/60/90일: 각각 검증 가능한 마일스톤 1개 설정(예: 모듈 1개 독립 납품).

구조(각 단계에 부여):
- 목표(이 단계 종료 시 신입이 무엇을 할 수 있어야 하는가).
- 체크리스트(구체 사항 + 담당자 + 완료 표시).
- 체크포인트(신입이 마일스톤 달성 시 누가 1:1 피드백하는지).

규율:
- 버디(직속 외 파트너) 지정 + 피드백 주기 명시(매주 1:1).
- 문서 먼저: '어떤 사람만 구두로 아는' 것을 문서화하고, 신입에게 추측하게 만드는 것은 NEVER.
- 태스크 난이도는 점진적: 먼저 작게 크게, 안전한 시행착오 여지를 준다.

산출: 단계별 체크리스트 + 마일스톤 표 + 피드백 주기 표 + 핵심 문서/링크 리스트.

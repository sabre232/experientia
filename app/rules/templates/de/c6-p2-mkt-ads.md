Bei der Erstellung von Werbetexten/Kampagnen den Rahmen nach Ziel wählen, eine Version pro Rahmen:

- PAS (Problem-Agitate-Solve): für die Konversion auf einen Pain-Point. Problem stellen → Kosten verstärken → Lösung + Handlungsanweisung geben.
- AIDA (Attention-Interest-Desire-Action): für Marke/langer Text. Aufmerksamkeit wecken → Interesse wecken → Verlangen erzeugen → zur Aktion führen.
- BAB (Before-After-Bridge): für Effektkontrast. Ist-Zustand → Ideal-Zustand → das Produkt ist die Brücke.
- 4Ps (Picture-Promise-Proof-Push): für hohen Warenkorb/Vertrauensbedarf. Vision zeichnen → Versprechen geben → Beleg zeigen → zur Aktion führen.

Gemeinsame Disziplin:
- Jede Version endet mit einer klaren CTA (Handlungsanweisung, singular, konkret).
- Belege (Daten/Beispiele/Zertifikate) sind real und überprüfbar; nie erfinden.
- Ein Hauptverkaufsargument pro Text; nie fünf in einem Absatz.

En faisant une analyse concurrentielle, respecter :

Périmètre :
- Choisir 2-4 concurrents directs (même cible, même scénario) ; lister d'abord la raison du choix.

Matrice de comparaison des fonctionnalités :
- Lignes = les points de fonctionnalité qui nous intéressent, colonnes = chaque concurrent ; cellule « présent/absent/partiel » + une phrase de note.
- Les points de fonctionnalité viennent de nos besoins ; NEVER lister toutes les fonctionnalités du concurrent.

Différences et opportunités :
- Pour chaque différence, trancher : c'est une barrière, un vide, ou de l'anecdotique, avec l'argument.
- Les opportunités se traduisent en « actions concrètes que nous pouvons faire » ; NEVER s'arrêter à « ils ont, nous n'avons pas ».

Discipline des preuves :
- Chaque « présent/absent » indique la source (site officiel / test réel / version + date) ; les tests réels sont marqués « testé ».
- La concurrence évolue, les conclusions indiquent la date d'analyse ; NEVER prendre une info ancienne pour l'état actuel.

코드 스타일:
- 저장소의 기존 스타일(인덴트, 명명, import 순서)을 따르고, 새 코드는 인접 코드와 일치시킨다. 무관한 파일을 손대서 포맷 변경하는 것은 NEVER.
- 주석은 코드 자체로 표현할 수 없는 제약만 쓴다. '여기서 X 호출'류의 쓸모없는 문구는 쓰지 않는다.

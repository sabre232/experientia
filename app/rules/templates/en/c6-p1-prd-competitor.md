Doing competitive analysis, follow:

Scope:
- Pick 2-4 direct competitors (same target user, same scenario); state the selection reason.

Feature matrix:
- Rows = features we care about, columns = each competitor; cells "yes/no/partial" + one-line note.
- Features come from our requirements — NEVER list every competitor feature.

Differences & opportunities:
- For each difference judge: moat, gap, or irrelevant — with reasoning.
- Opportunities land on "concrete actions we can take", NEVER stop at "they have it, we don't".

Evidence discipline:
- Each "yes/no" carries its source (official site / hands-on / version + date); hands-on items marked "verified".
- Competitors change; date-stamp the analysis — NEVER treat stale info as current.

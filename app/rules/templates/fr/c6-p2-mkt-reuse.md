En réécrivant un long texte en versions multi-plateformes, respecter :

D'abord extraire l'ossature du contenu : thèse centrale, données clés, phrases fortes, cas. Toutes les versions partagent la même source de faits ; jamais de contradiction de faits entre versions.

Réécriture par plateforme (pas une simple réduction) :
- Blog/média long : argumentation complète + sous-titres pour aérer.
- Post court (type X/Twitter) : un seul point + accroche en tête + hashtags.
- Script vidéo : phrases courtes à l'oral + indications visuelles + points de rythme.
- Affiche/infographie : 3-5 points + un titre principal.

Discipline :
- Les 3 premières secondes de chaque version décident du départ ou de la poursuite, l'accroche est en tête.
- Les données/citations restent cohérentes entre plateformes ; si la limite de caractères est dépassée, couper d'abord les exemples, pas la thèse.
- À la sortie, indiquer la plateforme et le nombre de caractères de chaque version, pour coller directement.

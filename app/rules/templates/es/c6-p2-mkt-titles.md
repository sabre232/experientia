Para un título, producir una versión desde cada uno de los cuatro ángulos, y luego elegir:

1. Dolor: apuntar directamente la contrariedad actual del usuario (« ¿Aún pierde noches por X? »).
2. Cifra: una promesa cuantificable (« Y en 3 pasos », « -40 % de coste »), las cifras deben ser reales y verificables.
3. Suspense: crear una brecha de información (« el 90 % de la gente no sabe Z »); nunca clickbait donde el contenido no coincide con el título.
4. Beneficio: decir directamente qué obtiene el usuario (« Recuperar el tiempo perdido en W »).

Requisitos:
- Cada versión ≤ 20 caracteres (seguir la plataforma si tiene su propio límite).
- 4 versiones sobre el mismo tema, marcando el ángulo de cada una, para que el usuario compare.
- Nunca una palabra clave sin relación con el contenido para captar tráfico.

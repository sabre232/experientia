En éditant/révisant, passer la checklist :

Couper les mots de remplissage :
- Supprimer « en fait / grosso modo / dans une certaine mesure / on peut dire / il faut noter que » et autres mots sans information.
- Supprimer les emphases en double (« très très », « totalement complètement », en garder un).

Passif vers actif :
- « a été complété » → « a complété » ; si on trouve le sujet de l'action, l'écrire.
- Découper les suites de passifs, sujet clair.

Jargon en langage clair :
- Le terme à sa première occurrence a une explication en langage clair ; éviter le jargon si possible.
- Le jargon comme « empowerment / levier / boucle fermée », sauf si le lecteur cible est de ce milieu, est remplacé par une formulation concrète.

Vérification des faits :
- Chiffrer, dater, nommer, citer un par un ; ce qui ne se vérifie pas est marqué « à vérifier ».
- Un même fait qui apparaît plusieurs fois dans le texte reste cohérent.

Livraison : la version révisée + une note de changement (quels types de problèmes, combien de fois), pour aider l'auteur à juger.

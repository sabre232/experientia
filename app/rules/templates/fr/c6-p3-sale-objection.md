En traitant une objection client, respecter :

Méthode (recevoir d'abord, puis transformer) :
- Reformuler et valider l'objection (« je comprends que X compte pour vous ») ; jamais de contre-attaque directe ou de nier le ressenti.
- Chercher la vraie cause : derrière l'objection se cache souvent une autre crainte (« vous diriez plutôt quel point vous inquiète ? »).
- Répondre par une preuve/un cas ; jamais de promesse à l'aveugle ; si on n'a pas la preuve, dire honnêtement « je confirme et je reviens vers vous » et le faire.
- Transformer : faire de l'objection une confirmation de type « si X est réglé, vous pouvez avancer ? ».

Réponses aux objections fréquentes (une version par cadre, contenu selon le produit réel) :
- Trop cher → ancrage de valeur + décomposition au temps unitaire/effet ; jamais de baisse directe.
- Je vais réfléchir → préciser ce que « réfléchir » recouvre (décideur / timing / budget).
- On a déjà quelque chose → questionner le point de douleur actuel, trouver la valeur ajoutée ; jamais de dénigrer la solution existante.
- Pas de budget → questionner le cycle budgétaire, proposer un paiement échelonné / une entrée à petite échelle.

Discipline :
- NEVER promettre l'inatteignable pour conclure (ça s'effondre à la livraison, la confiance est détruite).
- Noter chaque objection et son résultat de traitement, pour alimenter la base de scripts.

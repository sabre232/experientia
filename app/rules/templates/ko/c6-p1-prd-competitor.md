경쟁사 분석을 할 때 준수:

범위:
- 직접 경쟁사를 명확히 2-4개 선정(같은 목표 사용자, 같은 시나리오); 먼저 선정 이유를 나열.

기능 비교 매트릭스:
- 행 = 우리가 주목하는 기능점, 열 = 각 경쟁사; 셀은 '있음/없음/일부' + 한 줄 비고.
- 기능점은 우리의 요구사항에서 온다; 경쟁사 모든 기능을 나열하는 것은 NEVER.

차이와 기회:
- 각 차이점에 대해 판단: 장벽인가, 공백인가, 중요하지 않은가, 근거 제시.
- 기회는 '우리가 할 수 있는 구체 동작'으로 떨어뜨리고, '그들에게 있고 우리에게는 없다'에서 멈추는 것은 NEVER.

근거 규율:
- 각 '있음/없음'에 정보 출처를 명시(공식 사이트/실측/버전 번호 + 날짜); 실측한 것은 '실측 완료'로 표시.
- 경쟁사는 변하므로, 결론에는 분석 시점 주석을 달아라; 오래된 정보를 현재로 보는 것은 NEVER.

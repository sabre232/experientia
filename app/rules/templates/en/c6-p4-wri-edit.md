Editing/polishing, run this checklist:

Cut filler:
- Delete non-informative words ("actually", "basically", "to some extent", "it is worth noting").
- Delete repeated emphasis ("very very", "thoroughly and completely" — keep one).

Passive to active:
- "was completed by" -> "completed"; name the actor when it can be found.
- Break up consecutive passive sentences; make subjects explicit.

Jargon to plain:
- Gloss jargon in plain language on first use; avoid jargon when avoidable.
- Black-letter terms ("empower", "lever", "closed loop") only if the audience is that circle; otherwise replace with concrete words.

Fact check:
- Verify numbers, dates, names, citations one by one; unverifiable items marked "[to verify]".
- Same fact appearing multiple times must be consistent.

Deliver: revised version + a change log (what kind of issue, how many), so the author can judge.

Designing new-hire onboarding, follow:

Phased (typical 30/60/90):
- Week 1: environment/permissions/tools + meet the team + read key docs + first small task.
- Weeks 2-4: shadow existing flows + buddy + independently finish 1-2 low-risk tasks.
- 30/60/90 days: each with a verifiable milestone (e.g. independently deliver one module).

Structure (each phase gets):
- Goal (what the new hire should be able to do by the end).
- Checklist (concrete items + owner + completion signal).
- Checkpoint (who does a 1:1 when the milestone is hit).

Discipline:
- Assign a buddy (a non-manager peer) + set a feedback cadence (weekly 1:1).
- Docs first: turn "only known verbally by one person" into docs — NEVER make new hires guess.
- Task difficulty ramps: small first, with safe room to try and fail.

Output: phased checklist + milestone table + feedback cadence + key docs/links list.
